# Support / 使用支持

Maintainer / 维护者: [starlight-girl](https://github.com/starlight-girl).

Report bugs, installation problems, or questions through [GitHub Issues](https://github.com/starlight-girl/agent-engineering-verification-skills/issues).

Include the plugin edition and version, host version, reproduction steps, and a redacted excerpt of the error. Do not post secrets, private source, personal information, or unredacted logs. GitHub Issues are public. Community support has no promised response time.

反馈时提供插件版本、中文或英文版、宿主版本、复现步骤和脱敏错误摘要。不要提交密码、密钥、私有代码、个人信息或未经脱敏的日志。Issues 为公开页面；社区支持不承诺响应时限。
