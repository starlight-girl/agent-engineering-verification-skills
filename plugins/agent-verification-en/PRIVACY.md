# Privacy / 隐私说明

Applies to the Agent Verification English and Chinese skills-only plugin packages distributed by starlight-girl.

These packages contain static instructions and reference documents. They contain no publisher-operated server, account service, analytics, telemetry, or automatic upload mechanism. The package itself does not independently collect or retain conversation content, source code, logs, or personal data.

Your host (such as ChatGPT or Codex) processes prompts, files, tool results, and any authorized runtime observations according to its own policies and your settings. Installing these skills does not change those policies or grant additional tool permissions. Review the host's privacy terms before sharing sensitive material.

If you voluntarily submit a GitHub issue, its content and account information are handled by GitHub and may be publicly visible. Do not submit sensitive data. Manage or delete your posts through GitHub's controls and use the support Issues page for questions. The publisher does not operate a separate data store for this plugin.

本说明适用于 starlight-girl 发布的中文和英文纯技能插件。插件是静态指令与参考文档，不内置维护者服务器、账户服务、统计、遥测或自动上传机制；包本身不独立收集或保存对话、代码、日志或个人信息。

宿主 ChatGPT／Codex 按自身政策与用户设置处理提示、文件、工具结果和获授权的运行时观测；本插件不改变平台政策，也不增加工具权限。请在提供敏感内容前查看宿主隐私条款。

主动提交 GitHub Issue 的内容与账号资料由 GitHub 处理，可能公开可见。请勿提交敏感资料，通过 GitHub 管理或删除自己的帖子。插件维护者不运营独立的数据存储。
