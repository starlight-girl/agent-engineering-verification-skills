# Agent Verification EN

Version 1.2.0. Apache-2.0.

Read-only engineering verification workflows for tool-using AI agents: 11 scoped skills, two playbooks, and an inspector role. Distinguish test execution, observed reality, and requirement status. Runtime access depends on the host and user authorization; missing evidence remains unverified. Free, open source, no bundled server or telemetry.

Source and installation: https://github.com/starlight-girl/agent-engineering-verification-skills

Public OpenAI directory approval is separate from GitHub distribution.
