# Agent Verification 1.2.0 / 智能体工程验收插件

Free English and Chinese plugin editions are available as ZIP downloads and through the repository marketplace.

Each edition contains 11 scoped verification/diagnostic skills, two playbooks, and one Inspector role, with the original contracts preserved. Chinese workflows produce Chinese reports and include the complete original English contracts.

## Install / 安装

```sh
codex plugin marketplace add starlight-girl/agent-engineering-verification-skills --ref v1.2.0
codex plugin add agent-verification-zh@agent-engineering-verification
```

English: replace the second command with `codex plugin add agent-verification-en@agent-engineering-verification`.

Start a new chat. See [installation instructions](https://github.com/starlight-girl/agent-engineering-verification-skills/blob/v1.2.0/INSTALL.md) for desktop clients and download verification.

## Validation scope / 验证范围

ZIP integrity, all internal hashes, original-document parity, 14 skill entrypoints per edition, manifest metadata, icons, and local reference links have passed package checks. Chinese edition installed through the actual Codex plugin commands. These checks do not establish that arbitrary target projects pass runtime acceptance.

No publisher server, telemetry, credentials, purchases, or dependency installation are included. Apache-2.0.

GitHub public distribution is separate from OpenAI universal directory approval. This release does not claim an approved ChatGPT web/mobile directory listing.
